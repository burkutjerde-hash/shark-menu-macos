# Shark RV2000 Menu Bar Controller (macOS)

Shark RV2000 serisi robot supurge icin yerel ag uzerinden calisan macOS menu cubugu kontrol ve harita uygulamasi.

## Ozellikler
- Canli Vektorel Harita (Canvas tabanli oda poligonlari, duvarlar, dock ve robot pozu)
- Canli Telemetri & Durum (Pil yuzdesi, donanim durumlari, GIF animasyonlari)
- Robot Kontrolleri (Temizligi baslat/durdur, yuvaya gonder, fan gucu)
- Yerel REST API destegi (192.168.1.23:8080 uzerinden bagimsiz iletisim)

## Derleme
```bash
./build.sh
```
